Format d'interface préféré pour l'application

Comment souhaites-tu interagir avec le planner au quotidien ?

A

CLI Interactive (Terminal avec Typer & Rich)

Commandes rapides dans la console, menus interactifs et tableaux visuels colorés dans le terminal.

B

Interface Web locale (Streamlit)

Une interface graphique dans ton navigateur avec sélection déroulante des cinémas Pathé, curseurs horaires et planning visuel.

C

Les deux (Moteur partagé + CLI + UI Web Streamlit)

Un cœur Python/SQLite réutilisable avec à la fois la commande terminal rapide et le dashboard web interactif.
